# 录波分块 RMS 实现与验收

## 1. 目标与口径

主图显示有符号原始 AD；每个单相64点块读取成功后立即按 `sqrt(sum(AD²))` 计算 AD-RMS（硬件已完成N=64相关处理，软件不再除N），再乘1552标定系数并最后四舍五入为1位小数的 RMS(A)。6个时间段分别显示A/B/C三相，共18个RMS，不再计算384点总体RMS。协议细节见[故障录波协议解析](waveform-protocol.md)，公式见[RMS说明](waveform-rms-explained.md)。

## 2. Core模型和服务

- 原有请求顺序保持：向785写0000H选择故障第0条 → 等待 → 读768～770有效BCD时间 → 保存稳定软件补充毫秒 → 读1552 → 按段A/B/C顺序读18个64点块。
- frameLevel=(1552>>8)&0x0F；0/1/2对应框I/框II/框III和Rate=1/1.5/2，其余值失败。每AD安培系数=10000.0/22953.0×Rate。
- 大端寄存器先解释为有符号short，不交换字节。每块必须64点，平方累加使用double。2026-11-04用户确认硬件已完成N=64相关除法，当前软件返回Math.Sqrt(sumOfSquares)，不能再次除以samples.Count或64。
- WaveformBlockResult拥有64点独立只读副本、块定义、AD-RMS、RMS(A)，创建时即计算。不可先对逐点安培取整。
- 同段三相齐全后创建WaveformSegmentResult，包含64个三相对齐点及三个块结果。每相384点、3200Hz、0.3125ms间隔和源寄存器地址保持原规则。
- ReadAsync签名保持不变；WaveformReadProgress携带当前块结果、标定及可空CompletedSegment，仅每第三块附带新完成的段。最终WaveformData汇总6段及展开后的384点，不重新计算总体RMS。

## 3. 页面与状态

- 预览与上次完整结果分离。开始时清空预览，同段三相齐全后每次追加64点，未完成段留空；完整成功后才更新CurrentWaveformData及原始明细窗口。
- 进度仍为n/18，摘要显示已完成段数/6、每相点数、标定和时间来源。主图单位AD，RMS单位A。
- 显示六段交替底色和20ms分界，图表占满可用区域，不提供独立RMS面板，RMS仅通过悬停查看。Y轴按已完成段全部三相的AD极值扩展，完成后固定，显隐不改变范围。
- 鼠标通过图表坐标转换命中绘图区时间段，范围左闭右开[-80,40)，-60ms属于第二段；不依赖曲线命中，提示三相RMS和最近采样点时间/AD，未完成段仅提示未完成。命中的图段高亮，移出清除。
- 失败或取消丢弃新预览并恢复旧曲线、RMS、时间轴和Y轴；无历史结果时回到空态，保留失败段、相别和地址。每次操作有独立标识，结束后忽略迟到回调。
- 读取期间禁止导出。Shift+F8原始明细和uint16原始曲线保持原语义，只使用完整结果。
- 绝对时间规则保持：故障秒+稳定软件毫秒+(相对时间-首点相对时间)，补充毫秒明确标注为非设备实测。

## 4. Excel

- “波形数据”元数据包含读取时间、采样率、点数、1552原值、框架、Rate、故障时间、软件补充毫秒及分块RMS公式；删除总体RMS。
- 第11行为表头：类型、时间段、点号、相对时间(ms)、绝对采样时间、单位、A相、B相、C相。
- 每段64行采样后追加1行三相RMS，共390行数据。采样行单位AD、保留有符号整数；RMS行单位A、1位小数，点号和时间留空，加粗、浅色背景和顶边框，不合并单元格。
- 表头冻结并设置打印重复；主表不做跨汇总行筛选。“读取明细”保留1152行10列纯采样明细，可筛选并冻结表头，删除逐点电流(A)。
- 时间、AD、RMS保留数值；绝对时间直接按ticks换算Excel日期序列，防止DateTime.ToOADate丢弃不足1ms的间隔。日期显示到毫秒，相对时间保留4位小数。
- 所有RMS取自读块时的结果，导出不重新计算；Shift+F8专用16列原始Excel保持原样，其他设备/故障四列导出不变。

## 5. 模拟器与PDF回归

- 模拟器默认使用用户Excel录波明细的1152个原始值；--waveform-source pdf保留PDF18帧样本。两种模式均使用1552=0x0104（框II/Rate=1.5），地址间隙非法，不生成、平滑或修改波形。Excel没有标定信息，Rate=1.5仅为模拟配置。
- 保留18帧CRC、byte-count、拼接SHA-256、地址和逐点测试。
- 新口径验证B200H的64点AD-RMS=39830.990145865064，B580H=6.324555320336759及对应安培RMS。旧版4978.873768233133/0.7905694150420949及PDF整相384点统计仅作历史对照，不能作为当前函数基准。

## 6. 自动验收

1. 阻塞第二块请求时，第一块已经报告RMS，证明没有等待全量读取。
2. 第一、二块只更新进度，第三块开始显示64个三相点及RMS；每三块追加一段。
3. 覆盖硬件口径不再除N、全零、正负交替、short.MinValue、Rate映射、64点数量校验及只读快照。用户示例平方和24291643，新AD-RMS=4928.655293282337，Rate=1.5时显示3220.9A。
4. 覆盖首次/后续读取失败、取消、旧结果恢复及结束后迟到进度。
5. 覆盖全部时间段起点/末端、精确分界、非法坐标、隐藏全部曲线及未完成段悬停。
6. 验证Excel384行采样+6行RMS、1152行纯明细、单位、数值类型、逐点值、RMS一致性及细分时间精度。
7. 相关测试全部通过，全量回归不得新增失败。实施前基线173项中156通过、17失败，包含既有断言及系统字体权限问题；导出测试使用ClosedXML内置度量字体排除系统字体目录依赖。
