# 录波数据功能实现计划

## 1. 目标

在现有录波数据页实现故障时间前置校验、稳定软件毫秒、绝对时间轴、1552 框架等级标定、固定录波区读取、三相安培曲线、显隐控制、A-RMS、原始点核查和 Excel 导出；使用 PDF 截图中的真实帧作为端序、符号位、CRC 和相对时间轴回归测试。协议细节见 [故障录波协议解析](waveform-protocol.md)。

## 2. Core 模型和服务

- 新增 `WaveformPhase`、`WaveformBlockDefinition`、`WaveformPoint`、`WaveformCalibration`、`WaveformData` 和 `WaveformReadProgress`。
- `WaveformCatalog` 固化 18 个块、每块 64 点、每相 384 点、3200 Hz 和 0.3125 ms 采样间隔。
- `IFaultRecordService.ReadTimestampAsync` 固定向 785 写入 `0000H`，选择故障第 0 条记录（最近一条）、等待准备时间、读取 768～770，并用公共 BCD 时间解析器返回强类型 `DateTime`；录波页不跟随故障数据页的类型和序号选择。
- `IWaveformTimeOffsetStore` 以秒级故障时间为唯一键，生成并持久化 `0～999 ms`；`WaveformTiming` 负责把相对毫秒转换成绝对时间。
- `IWaveformDataService.ReadAsync` 在前置时间流程成功后读取 1552，再按段、A/B/C 顺序调用现有 `IModbusRtuClient`。
- `ushort` 使用 `unchecked((short)value)` 转成有符号 AD；不交换寄存器内字节。
- 故障时间缺失/非法、毫秒无法持久化、1552 读取失败、框架等级非法或任何块失败立即终止，不生成新的页面结果；调用方保留上一次完整结果。
- `frameLevel=(1552>>8)&0x0F`，数值 0/1/2 在页面分别显示为框I/框II/框III，对应 Rate 1/1.5/2；`A=有符号AD×10000÷22953×Rate`，最终安培结果按通常四舍五入保留 1 位小数。
- 对每相 384 点保留 AD-RMS 并计算安培 RMS，同时保留每个点对应的三个源寄存器地址。

## 3. PDF 回归测试

- 固化 PDF 第 2～11 页全部 18 个完整 133 字节响应帧，校验拼接 SHA-256，防止人工转录后静默变化。
- 逐帧校验帧长、byte-count、CRC、64 点数量，并逐块比对模拟器的 1152 个寄存器值。
- 锁定 `1A30H → 6704`、`FEC0H → -320`，防止误加小端交换。
- 校验 B200H RMS `4978.873768233133` 和 B580H RMS `0.7905694150420949`。
- 校验三相各 384 点的拼接顺序、完整 RMS、段首、段末时间以及完整 `-80～39.6875 ms` 时间轴。

## 4. 页面

- 替换“录波数据暂不可用”占位页。
- 顶部增加立即读取、导出 Excel、A/B/C 显隐开关和 `n/18` 进度。
- 使用 LiveCharts2 绘制三条折线，内部 X 值仍是相对毫秒，但标签转换为 `HH:mm:ss.fff` 的绝对录波时间，工具提示显示完整绝对采样时间；Y 轴为安培，三相共用一次读取后固定的 Y 轴范围。
- 横轴继续每隔 20 ms 绘制一条虚线；摘要明确显示原始故障秒、软件补充毫秒、首尾时间、记录类型和序号。
- 显示读取时间、采样率、每相点数、框I/框II/框III、Rate 和 A/B/C 安培 RMS。
- Shift+F8 原始点明细继续显示 uint16 原值、有符号 AD 和源地址，“原始值画图”继续使用 uint16。
- 读取失败保留旧曲线并显示具体失败块；没有完整数据时禁止导出。

## 5. Excel

扩展现有导出服务，增加 `WaveformExcelExportContext`：

- `波形数据`：读取元数据、1552 原值、框架等级、Rate、公式、三相安培 RMS、时间来源和软件补充毫秒，以及 384 行“序号、相对时间、数值型绝对时间、A/B/C 安培”。
- `读取明细`：1152 行“段、时间段、相别、局部/全局序号、相对时间、数值型绝对时间、地址十进制/HEX、有符号 AD、安培”。
- 采样时间、AD 和安培写为数值单元格，便于 Excel 继续计算和绘图。
- Shift+F8 明细专用 Excel 严格保持当前 16 列原始表格。
- 现有设备/故障四列导出行为和测试保持不变。

## 6. 模拟器

- 1552 返回 `0x0204`（框III，即框架等级原值2；Rate=2；低8位序值4）；仅添加 18 个合法录波块，地址间隙仍视为非法地址。
- 直接复现 PDF 全部 18 个响应帧中的 1152 个采样值，不生成或平滑人工波形。
- 负数按 `short` 补码写入寄存器，响应继续按 Modbus 大端发送。

## 7. 验收

1. 全部 18 个 PDF 帧的长度、CRC、拼接 SHA-256、块顺序和模拟器逐点一致性测试通过。
2. 请求顺序固定为“向 785 写 `0000H` 选择故障第 0 条记录 → 读 768～770 → 持久化稳定毫秒 → 读 1552/数量1 → 18 个数量64的录波请求”；进度分母仍为18。
3. 无效故障时间时弹窗和状态栏给出原因，且 1552 与 18 个录波地址均不得被请求；上一次完整曲线保持不变。
4. 页面、Excel 和模拟器对同一点给出一致的相对时间、绝对时间、有符号 AD 与安培值，并验证跨秒、跨分钟。
5. 深浅主题、窗口缩放、三相显隐、绝对时间标签、工具提示和失败保留完成手工检查。
6. 解决方案构建零警告，全部自动化测试通过。
7. 字节序、AD→A 公式和 Rate 映射已由厂商确认；实机继续确认采样率、跨段连续性和录波冻结规则。软件补充毫秒始终标注为非设备实测值。
