# 录波数据功能实现计划

## 1. 目标

在现有录波数据页实现固定录波区读取、三相曲线、显隐控制、AD-RMS 和 Excel 导出；使用 PDF 截图中的真实帧作为端序、符号位、CRC 和时间轴回归测试。协议细节见 [故障录波协议解析](waveform-protocol.md)。

## 2. Core 模型和服务

- 新增 `WaveformPhase`、`WaveformBlockDefinition`、`WaveformPoint`、`WaveformData` 和 `WaveformReadProgress`。
- `WaveformCatalog` 固化 18 个块、每块 64 点、每相 384 点、3200 Hz 和 0.3125 ms 采样间隔。
- `IWaveformDataService.ReadAsync` 按段、A/B/C 顺序调用现有 `IModbusRtuClient`。
- `ushort` 使用 `unchecked((short)value)` 转成有符号 AD；不交换寄存器内字节。
- 任何块失败立即终止，不生成残缺 `WaveformData`；调用方保留上一次完整结果。
- 对每相 384 点计算 RMS，并保留每个点对应的三个源寄存器地址。

## 3. PDF 回归测试

- 固化 PDF 第 2～11 页全部 18 个完整 133 字节响应帧，校验拼接 SHA-256，防止人工转录后静默变化。
- 逐帧校验帧长、byte-count、CRC、64 点数量，并逐块比对模拟器的 1152 个寄存器值。
- 锁定 `1A30H → 6704`、`FEC0H → -320`，防止误加小端交换。
- 校验 B200H RMS `4978.873768233133` 和 B580H RMS `0.7905694150420949`。
- 校验三相各 384 点的拼接顺序、完整 RMS、段首、段末时间以及完整 `-80～39.6875 ms` 时间轴。

## 4. 页面

- 替换“录波数据暂不可用”占位页。
- 顶部增加立即读取、导出 Excel、A/B/C 显隐开关和 `n/18` 进度。
- 使用 LiveCharts2 绘制三条折线，X 轴为相对故障时间 ms，Y 轴为 AD。
- 显示读取时间、采样率、每相点数和 A/B/C AD-RMS。
- 读取失败保留旧曲线并显示具体失败块；没有完整数据时禁止导出。

## 5. Excel

扩展现有导出服务，增加 `WaveformExcelExportContext`：

- `波形数据`：读取元数据、三相 RMS，以及 384 行“序号、时间、A/B/C AD”。
- `读取明细`：1152 行“段、时间段、相别、局部/全局序号、时间、地址十进制/HEX、AD”。
- 采样时间和 AD 写为数值单元格，便于 Excel 继续计算和绘图。
- 现有设备/故障四列导出行为和测试保持不变。

## 6. 模拟器

- 仅添加 18 个合法录波块，地址间隙仍视为非法地址。
- 直接复现 PDF 全部 18 个响应帧中的 1152 个采样值，不生成或平滑人工波形。
- 负数按 `short` 补码写入寄存器，响应继续按 Modbus 大端发送。

## 7. 验收

1. 全部 18 个 PDF 帧的长度、CRC、拼接 SHA-256、块顺序和模拟器逐点一致性测试通过。
2. 服务严格发出 18 个、每个数量 64 的请求。
3. 页面、Excel 和模拟器对同一点给出一致的 AD 值。
4. 深浅主题、窗口缩放、三相显隐、工具提示和失败保留完成手工检查。
5. 解决方案构建零警告，全部自动化测试通过。
6. 字节序已由厂商确认为大端；实机继续确认采样率、跨段连续性和录波冻结规则；没有 AD 标定前不显示安培。
