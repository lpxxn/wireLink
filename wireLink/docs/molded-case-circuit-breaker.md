# 塑壳断路器协议实现

本实现依据《BM3E+BM30E+BMCE 通讯协议》。文档中的 `Uint` 按单个 `UInt16` 处理，地址按报文中的十六进制寄存器地址直接使用，不做减一转换。通信继续使用 Modbus RTU、03H、CRC16 和 8N1。

## 设备选择与连接

设备类型包括“框架控制器”和“塑壳断路器”，选择结果保存在应用设置中。框架控制器连接测试和地址扫描读取 `0100H`，塑壳断路器读取 `0001H`。

串口打开或设备已经连接时仍可切换设备类型，但通信操作进行期间不能切换。切换会停止自动刷新、清空所有设备专属数据、将状态改为未连接，并保留串口、端口、波特率、从机地址和超时设置。软件不会自动探测，用户必须重新点击“连接测试”。

塑壳断路器支持的文档波特率为 2400、4800、9600、19200 BPS；公共下拉框还保留框架控制器原有的 38400、115200 BPS。

## 设备数据

设备数据分两块读取：`0001H～0007H` 和 `0032H～0035H`。后一组在原协议中位于故障记录章节，但按产品要求仍展示在“设备数据”页。

| 地址 | 字段 | 解析 |
|---:|---|---|
| `0001H～0006H` | A/B/C/N 相电流、接地电流、最大相电流 | `UInt16 × 1`，单位 A |
| `0007H` | 最大电流所在相 | 0/1/2/3 对应 A/B/C/N 相 |
| `0032H` | 故障类型记录 | 按协议 6.2 枚举 |
| `0033H` | 故障最大相电流记录 | `UInt16 × 1`，不显示单位 |
| `0034H` | 故障电流所在相记录 | 0/1/2/3 对应 A/B/C/N 相 |
| `0035H` | 故障时间记录 | 原值 ÷50，单位 s |

`0032H` 已知值为 0 无故障、1 瞬时故障、2 漏电故障、4 接地故障、8 短延时故障、16 长延时故障；32、33、34、36、40、48 均显示“故障未读取”。其他值保留十进制原值并显示协议警告。

## 保护数据

保护数据使用 `0016H～001CH` 和 `001EH～001FH` 两个读取块。`001DH` 是协议保留的未用漏电电流地址，软件不读取该地址，只显示固定值 `0`。

| 地址 | 字段 | 解析 |
|---:|---|---|
| `0016H`、`0018H`、`001AH`、`001BH`、`001FH` | 各保护电流 | `UInt16 × 1`，单位 A |
| `0017H` | 长延时时间 T1 | 0=OFF；1～150 对应 1～150 s |
| `0019H` | 短延时时间 T2 | 0=OFF；3/5/10/15 对应 0.06/0.1/0.2/0.3 s |
| `001CH` | 接地时间 Tg | 0～7 对应 0.1～0.8 s；8=报警 |
| `001DH` | 漏电电流（未用） | 不读取，固定显示 0 |
| `001EH` | 预报警时间 Tp | 0～9 对应 0.1～1.0 s |

离散表中没有定义的原值不参与推测换算，界面显示十进制原值和协议警告。本阶段所有保护参数均只读，不调用 06H 或 10H 写入。

## 页面和错误处理

- 框架控制器显示“设备数据、录波数据、故障数据”。
- 塑壳断路器显示“设备数据、保护数据”；设备数据支持自动刷新，保护数据只支持手动读取。
- 塑壳断路器模式隐藏 BW1/BW3 和故障记录等待时间等框架专属设置。
- 每个读取块独立处理：一个块失败不会丢弃另一个块的成功结果，失败块保留上次成功值并标记过期。
- 设备数据和保护数据均可导出 Excel，导出内容与当前表格页面显示一致。
