# 录波 RMS 公式与解析代码说明

## 1. 当前采用的硬件口径（2026-11-04 更新）

用户确认：**硬件输出的值已经完成 N=64 相关的除法处理，软件不再除以 N。** `WaveformSampleDecoder.CalculateRms` 已由用户修改为直接对平方和开方，本文按这一设备口径记录。

当前软件公式：

```text
AD-RMS = sqrt(sum(AD[i]^2))
RMS(A) = AD-RMS × (10000.0 / 22953.0) × Rate
```

处理顺序固定为：**有符号 AD → 每个值平方 → 平方和 → 开平方 → 按 Rate 换算安培 → 最后保留1位小数**。

- 每个单相块仍为64点；64用于块完整性校验和时间轴，不再作为软件 RMS 的除数。
- 不再使用 `sqrt(sum(AD[i]^2) / 64)`，也不能在开方后再除以64。
- 不对采样点再次进行硬件归一化，也不改变图上和Excel中的原始AD值。
- 本约定适用于当前设备输出，不代表修改通用RMS的数学定义；不能直接推广到未经同样硬件处理的其他信号。

### 变更记录

| 项目 | 旧软件口径（已停用） | 当前设备口径 |
|---|---|---|
| 平方和处理 | 软件再除以采样点数 | 硬件已完成对应处理，软件不再除N |
| AD结果 | `sqrt(sum(AD²) / N)` | `sqrt(sum(AD²))` |
| 点数用途 | 分母及点数校验 | 点数校验、时间轴和显示 |
| 64点下新旧结果关系 | 旧值 | 新值是旧值的 `sqrt(64)=8` 倍 |
| 安培换算 | 乘每AD安培系数 | 同一系数不变，仍最后才取1位小数 |

该变更依据用户对硬件处理方式的确认，不是由“64点、20ms”自行推导出的通用结论。PDF中的通用公式与当前设备输出的处理约定需要分开看待。

## 2. 与通用RMS公式的区别

对于未经相关预处理的普通瞬时信号，通用离散RMS定义仍是：

```text
通用RMS = sqrt(sum(x[i]^2) / N)
```

但本项目读取的是当前硬件输出的AD值。按上述确认，软件接收后采用：

```text
当前硬件AD结果 = sqrt(sum(AD[i]^2))
```

从纯数学运算看，后者是平方和开根（root-sum-square）；项目沿用“AD-RMS / RMS(A)”的字段和界面名称。后续维护时应以设备输出约定解释这些字段，不能因为看到“RMS”这个名称又机械加回 `/N`。

如果未来接入不同型号或固件，必须先确认其数据是否具有相同预处理，不能默认沿用本设备规则。本文也不反推出“每个瞬时电流一定等于某个值除以64”等未经确认的硬件内部公式。

## 3. 当前代码与调用关系

代码位置：[WaveformCatalog.cs](../src/WireLink.Core/Registers/WaveformCatalog.cs)。核心逻辑为：

```csharp
public static double CalculateRms(IEnumerable<short> values)
{
    var samples = values as IReadOnlyCollection<short> ?? values.ToArray();
    if (samples.Count == 0) return 0;

    var sumOfSquares = samples.Sum(value => (double)value * value);
    // 硬件已完成 N=64 相关处理，软件不再除以 N。
    return Math.Sqrt(sumOfSquares);
}
```

说明：

- 空集合返回0是这个工具函数的防御行为；实际录波读取仍必须恰好成功返回64点，空块或残缺块直接失败。
- 先将值转为double再平方，避免多个int16平方累加时发生int溢出。
- 正值和负值都先平方，不会互相抵消。
- 函数本身不读取设备，也不进行端序转换、安培换算或四舍五入。

`WaveformBlockResult.Create`在每个单相块成功读取后立即调用该函数，保存AD结果，再计算：

```csharp
AmperesRms = WaveformCalibration.RoundAmperes(
    AdRms * calibration.AmperesPerAd);
```

同段A/B/C三块齐全后，生成只读的`WaveformSegmentResult`并立即预览。最终结果只汇总已有6段，不重新对每相384点计算一次总体值。

## 4. 报文解析规则保持不变

```text
接收响应并校验地址、功能码、字节数、长度和CRC
→ 按Modbus大端还原ushort
→ 按16位补码重新解释为short
→ 检查当前单相块恰好64点
→ 计算sqrt(sum(AD²))
→ 乘安培系数，最后保留1位小数
```

示例：

| 线路字节 | 寄存器原值 | 有符号AD |
|---|---:|---:|
| `1A 30` | `0x1A30 = 6704` | 6704 |
| `FE C0` | `0xFEC0 = 65216` | -320 |
| `FF FF` | `0xFFFF = 65535` | -1 |

必须使用有符号结果参与平方；不能把65216当成-320的采样值。寄存器内不额外交换字节。PDF“小端”的文字与实际帧及既有厂商端序确认不一致，仍沿用大端解析。

任一块失败，不得补零，不得将上一次完整录波与本次部分结果拼接。读取失败或取消时，页面撤销本次预览并恢复上次完整结果。

## 5. 安培标定保持不变

从寄存器1552（0x0610）提取框架等级：

```text
frameLevel = (register1552 >> 8) & 0x0F
```

| 等级原值 | 框架 | Rate |
|---:|---|---:|
| 0 | 框I | 1 |
| 1 | 框II | 1.5 |
| 2 | 框III | 2 |

3～15没有确认倍率，读取失败，不猜测。bit0～bit7和bit12～bit15不参与录波换算。

```text
每AD安培系数 = 10000.0 / 22953.0 × Rate
RMS(A) = sqrt(sum(AD[i]^2)) × 每AD安培系数
```

默认模拟标定为1552=`0x0104`、框II、Rate=1.5。AD平方和与开方阶段均不取整；安培结果最后使用`MidpointRounding.AwayFromZero`保留1位小数。不能先对每个点的安培值取整再统计。

## 6. 用户64点示例：当前结果为3220.9 A

用户提供的64点示例以`433, 354, 273, 191, …`开头，以`649, 583, 511`结束，与内置Excel样本第一段C相一致。

```text
点数              = 64
平方和            = 24291643
当前AD-RMS        = sqrt(24291643)
                  = 4928.655293282337 AD
Rate              = 1.5（框II）
当前安培RMS       = 4928.655293282337 × (10000.0 / 22953.0) × 1.5
                  = 3220.922293348802 A
最终显示          = 3220.9 A
```

下列值仅用于辨认旧口径，不再作为当前设备函数的验收结果：

```text
旧AD-RMS          = sqrt(24291643 / 64) = 616.0819116602921 AD
旧Rate=1.5结果    = 402.6152866686003 A，显示402.6 A
```

同一64点块、同一Rate下，新结果在最终四舍五入前是旧结果的8倍。不能把已经保留1位小数的402.6直接乘8来生成新显示值，必须从原始平方和重新计算。

## 7. PDF样例的新旧数值对照

原始响应帧、CRC、采样值和地址均不修改，只调整软件结果的解释与验收基准。

| 单相块 | 点数 | 平方和 | 旧口径：sqrt(sum/N)，已停用 | 当前：sqrt(sum) |
|---|---:|---:|---:|---:|
| B200H，A相，-40～-20ms | 64 | 1586507776 | 4978.873768233133 | 39830.990145865064 |
| B580H，C相，20～40ms | 64 | 40 | 0.7905694150420949 | 6.324555320336759 |

例如B580H包含30个0、21个1、11个-1、2个2，因此：

```text
平方和 = 30×0² + 21×1² + 11×(-1)² + 2×2² = 40
当前软件结果 = sqrt(40) = 6.324555320336759 AD
框II换算结果 = 6.324555320336759 × (10000.0 / 22953.0) × 1.5
            = 4.133156005970958 A → 4.1 A
```

PDF整相384点的历史普通RMS统计仅用于理解旧文档，不是当前按64点单相块工作的设备函数基准。

## 8. 分块、页面与Excel的口径

6个时间段仍是`-80～-60、-60～-40、-40～-20、-20～0、0～20、20～40 ms`；每段A/B/C各64点，共18个块结果。硬件归一化口径的变更不改变块划分和0.3125ms采样时间间隔。

主图和Excel采样行保留有符号AD原值。主图隐藏Y轴标题和数值刻度，保留纵轴范围及网格，并移除顶部“曲线：AD；RMS：A”说明。主图占满可用区域，鼠标按横坐标命中左闭右开时间段，悬停显示该段三相安培RMS；提示框以命中时间段的水平中心定位在该段顶部，靠近绘图区左右边缘时自动限位，文本尺寸变化时重新定位，不再固定于左上角。移出绘图区或调整图表尺寸时清除提示，下次鼠标命中后按新坐标定位；没有独立RMS面板。未完成段不显示旧RMS。

Excel“波形数据”仍为384行采样加6行三相RMS，RMS行单位A；“读取明细”仍为1152行纯采样明细，Shift+F8专用16列原始表不变。导出使用读块时计算好的结果，不重新计算。

## 9. F9计算器与维护待同步项

F9打开独立计算窗口，无需连接设备，默认Rate=1.5。输入应是当前硬件口径的有符号AD数据。常规录波块是64点；窗口显示的N是输入点数，不能再作为软件除数。任意点数的输入只能用于运算核对，不能据此证明符合设备64点完整块条件。
